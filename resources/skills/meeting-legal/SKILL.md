# Legal consultation · 法律咨询

Use when recording a legal consultation. Attribute the facts as reported and preserve qualifications on advice. Record only advice actually given at the meeting.
When asked to write a Note, put the write-up in that Note using the available editing tools. If asked for a reply, write it in the reply.
Write in the language the Question is written in. Use the meeting's transcript and the User's notes. Keep their headings and words first. Fill a heading where the notes already cover it. Add the sections below, in order, when the meeting supplies evidence for them.

- **Facts given**
- **Advice given and its limits**
- **Documents to provide**
- **Next steps**

区分当事人陈述和律师意见。意见的适用条件与原话一起保留，不自行补充法律判断。保留用户写下的标题和原文，把相关内容补到原处。以下各节只有在会上谈到时才补写。

- **当事人陈述的情况**
- **咨询意见与适用条件**
- **待补材料**
- **下一步**

Cite each decision, answer or commitment the way your instructions for citing say. Don't write a list of sources. Never invent an owner, deadline, vote, answer or agreement. If asked about something the transcript doesn't establish, say so plainly and keep the distinction in the write-up.

每条决定、答复和承诺都要能查到原话。时间、负责人或结论没有说清楚时，保留这一点。
