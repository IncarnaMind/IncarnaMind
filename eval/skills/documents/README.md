# Test Documents for the finance and law Skills (#1938)

Every Document in `en/` and `zh-CN/` was written for this repository in a fictional organisation's
voice. The companies, banks, courts, arbitral institutions and people in them are invented: Halden
Quay Logistics Limited, Merrowgate Bank plc, Ravensworth Analytics Ltd, Kestrel Health Systems Ltd,
海川冷链物流有限公司, 澜石银行股份有限公司, 远岚科技有限公司, 青禾健康系统有限公司 and everyone
named beside them. Nothing here describes a real company, person, agreement or proceeding, and no
text is copied from another source.

By the IncarnaMind contributors, released under CC0 1.0 (public domain dedication):
https://creativecommons.org/publicdomain/zero/1.0/legalcode

The Chinese Documents were written in Chinese, not translated from the English ones. The two
languages describe the same invented matters so that each Skill can be checked in both.

Each Document ends with the same line saying its companies and people are fictional; a test keeps
that line, so a Document can't enter the set without its provenance.
