# 你的数据去哪了

[English](where-your-data-goes.md) · **简体中文**

IncarnaMind 在本机读取、搜索和索引文件。它没有账号，也没有存放这些文件的服务器。只有在你选择服务、界面写明发送什么时，数据才会离开本机；本机模型不发送任何内容。“设置 → 隐私”实时列出每一项，每个字段见 [privacy.md](privacy.md)（英文）。

会改动内容的连接器工具会先询问，并说明回答读过哪些类型的内容，除非你设为 `始终允许`（回答读过网页、别人的文件，或笔记里别人写的文字后仍会询问）；只读工具不询问。

`技能脚本在这台电脑上运行，可发送它读取的内容。每个脚本运行前都会询问，除非你设为“始终允许”。` 在 Windows 上，以及没有 bubblewrap 的 Linux 上，脚本不受任何限制，可以联网。

同一条聊天流程还会发送：回答读取的笔记、命令找到的内容，以及 `做成技能` 用来起草的笔记文字；模型不能使用工具时，还会把问题改写并翻译成搜索词，发往快速任务模型（可能是另一家服务）。快速任务模型还会收到回答及其段落，用于找出回答中每个引用对应的引文；助手的回答可以修改笔记或运行命令时，它还会收到该回复、回复回答的问题，以及回答的工具实际做了什么的记录，用于核对回复中说做了的改动。具体限制见 [privacy.md](privacy.md)（英文）。

## 没有你的选择，不会有你的内容离开

开启 `所有内容都留在这台电脑上` 后，上面的云端发送都会停止，或只用本机模型，使用数据也会关闭并保持关闭。仍会进行：安装版启动时检查更新（发往 GitHub，可关闭）；从 huggingface.co 及其镜像、设置好后的自有副本下载模型，以及从 github.com 下载 IncarnaMind 自己的 Python（在 macOS 和 Linux 上），还有发往 huggingface.co 和 hf-mirror.com、用于选择模型来源的请求，以及 Ollama 拉取模型（不传你的内容）；如果你开启了崩溃报告，它仍会发送（发送前已去掉你的内容；报告包含错误、出错的时间和位置、应用版本、系统及其版本、电脑的芯片类型和型号系列、处理器数量和内存大小，以及 Electron、Chrome 和 Node 的版本）；你指定的网页等你允许后再抓取；本机连接器仍会工作，并可自行联网。

使用数据只来自带分析项目的版本，且只在你选择发送后发送（测试版在你关闭前会发送）；开启期间，每周还会发送一个事件，内容是那一周模型花费的大致区间、付费路线的类型、花费最多的服务类型，以及回答和核对的次数，每个字段见 [privacy.md](privacy.md)（英文）。崩溃报告需你开启；用 ChatGPT 订阅、Claude 账号或 GitHub 登录时，只联系对应的服务。

你自己发出去的导出文件会带上你文档中的引文和文档名称；可分享的网页还包括每段引文前后的文字和所在页面的部分截图。

密钥留在这台电脑上，只发给对应的服务。例外是自有智能体的配对密钥：一份明文副本在智能体的设置、安装命令或安装包中，任何以你的账号运行的程序都能读到，请妥善保管。没有同步：不会上传到 IncarnaMind 账号，因为没有账号。
