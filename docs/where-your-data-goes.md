# Where your data goes

**English** · [简体中文](where-your-data-goes.zh-CN.md)

IncarnaMind reads, searches and indexes your files here. It has no account or server for them. Data leaves only to a service you choose, where a line says what goes; a model on this computer sends nothing. Settings → Privacy lists every flow; [privacy.md](privacy.md) has every field.

| What you use | What leaves | Goes to | When |
| --- | --- | --- | --- |
| A Question | The Question and its context: the Blocks above it, except the Blocks of your text you excluded; in the assistant, earlier messages and the Note in focus; up to 30 Note names, the most recently changed, noting which an Answer wrote, if it can read Notes; a Note a Question names, up to about 12,000 tokens of it; the Passages found or read, with their Document names and pages; a picture you select in a note to ask about; the names, Folders and Tags of up to 50 Documents and of the notes a Question or a command finds; the Search scope as the composer's chip shows it: up to 10 Folders and 10 Tags by name, each with its Document count, how many more there are, and the number of Documents picked one by one; with no Search scope, All Documents with the number of Documents it searches and the number of Folders left out (not searched, and not named), and the Folder in front — the Note's, or the Library's open Folder when the Question has no Note — with its Document count, up to 10 of its Document names and how many more, else up to 10 of your Folders that hold Documents, with their Document counts and how many more; a Folder that keeps its work inside it is named only when you ask from inside it or search only inside it; Connector and Skill-script results, the names and descriptions of Skills that are on, the instructions and files of Skills the Answer loads, a capped Analysis report, and live Meeting Transcript lines. A Connector Tool that can change something asks first, saying what kinds of text the Answer read, unless you set it to `Always allow` (after the Answer reads a web page, someone else's file, or someone else's text in the Note, it asks anyway); a read-only Tool runs without asking.

`Skill scripts run here and can send what they read. Each asks before it runs, unless you set it to Always allow.` On Windows, and on Linux without bubblewrap, nothing confines a script, so it can reach the network.

Also on the chat flow: a Note the assistant reads, what a command found, and the Note text `Make this a Skill` drafts from; when the model cannot use Tools, the Question rewritten and translated as search queries to the quick-tasks model, which can be another provider. The quick-tasks model also receives an Answer with its Passages, to find the quotes behind its Citations, and, after an assistant turn that could change your notes or run a command, the reply with the Question it answers and the record of what the Answer's Tools did, to check what the reply says was changed. The record holds each Tool's name and outcome; the names and internal ids of the Notes and items it touched, and of the Note you were in; the part of a Note it named; up to six of your sentences that an edit took out and up to six it rewrote, each cut at 110 characters; a command's input and its result, which can hold a saved file's name and path, a setting's name with its old and new value, the Folder and Tag names it proposed and the names of Tags it merged, what else you asked as the command passed it on, and a failed command's message; and counts. This is the one check that receives internal ids or a file path. [privacy.md](privacy.md) has the limits.

## Nothing of yours goes without a choice

With `Keep everything on this computer` on, every cloud flow above stops or uses a local model, and usage data is turned off and stays off. Still happening: update checks to GitHub at startup in the installed app, unless off; model downloads from huggingface.co and its mirrors, IncarnaMind's copies once set up, and IncarnaMind's own Python from github.com (on macOS and Linux), with the request to huggingface.co and hf-mirror.com that picks the model source, plus Ollama pulls (nothing of yours); crash reports, if you turned them on (stripped of your content first; they hold the error, when and where it happened, the app version, your system and its version, your computer's chip type and model family, its processor count and memory size, and the versions of Electron, Chrome and Node); a page you name waits for you to let it go; and a local Connector keeps working and can reach the network itself.

Usage data goes only from a build with an analytics project and only if you choose Send (a test build sends until you turn it off); while it is on, one event a week also says roughly what that week's model calls cost, as a range, the kind of route that paid, the kind of provider most of that spend went to, and how many Answers and checks there were; [privacy.md](privacy.md) lists every field. Crash reports only if you turn them on; sign-ins to ChatGPT, a Claude account or GitHub go only to that service.

An export you send yourself carries quotes from your Documents with their names; a web page to share also holds the passage around each quote and a picture of part of its page.

Your keys stay here and go only to their own service, except an AI agent's pairing key: a plain-text copy is in the agent's settings, setup command or install bundle, and any process under your account can read it, so keep it private. There is no sync: nothing is uploaded to an IncarnaMind account; there isn't one.
