# Security policy

## Report a vulnerability

Please report a vulnerability privately, not in a public issue or discussion. Open this repository's **Security** tab, choose **Report a vulnerability**, and say what you found, which version it affects and how to reproduce it. We acknowledge a report as soon as we can and tell you when it is fixed.

## What to report

- A way to read or change a User's Documents, Minds or settings without the User's consent, to run code on their computer, or to reach their API keys or sign-ins.
- A request that sends a User's content somewhere they did not allow. [docs/privacy.md](docs/privacy.md) lists everything that can leave and what it sends.

A wrong Answer, or a check mark that is wrong, is not a security problem: open an issue. Neither is anything that needs control of the User's computer to begin with.

## Supported versions

IncarnaMind is in alpha. Only the latest pre-release on the [Releases page](https://github.com/IncarnaMind/IncarnaMind/releases) gets fixes.
